## Recent changelog highlights

Source: [GitHub Changelog](https://github.blog/changelog/), October 2026.

- **Stacked pull requests are generally available** (Oct 6): break large changes into a chain of smaller, reviewable pull requests.
- **Local sandboxing for GitHub Copilot is generally available** (Oct 7): run Copilot more safely on your machine.
- **AI Scan for pull requests** and **agentic autofix for code scanning alerts** are generally available (Oct 15).
- **GitHub Actions workflow lockfiles** are in public preview (Oct 14).
- **GitHub package firewall** is in public preview (Oct 20).
- **Bulk migrate branch protections to rulesets** for a repository (Oct 20).
